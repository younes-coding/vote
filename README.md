## 📌 نبذة عن المشروع
كتيب إلكتروني تفاعلي متقدم مصمم بأحدث معايير الواجهات الأمامية والنشر الرقمي المتخصص في المحتوى العربي اتجاه اليمين إلى اليسار (RTL). يُجسد البرنامج الانتخابي الواقعي لحزب جبهة المستقبل لانتخابات المجلس الشعبي الولائي لولاية تلمسان 2026.

يحتوي الكتيب على كافة المحاور التنموية الخمسة، الواقع الإحصائي، الخطط الإجرائية، خارطة الطريق الكبرى «البيت القصيد»، الرسوم البيانية التفاعلية المعتمدة على بيانات دقيقة، وقوائم المترشحين وإرشادات التصويت الصحيحة.

---

## 🚀 المميزات والوظائف الفنية

1. **نظام تقليب الصفحات (Flipbook) وقراءة مستمرة (Continuous Mode)**:
   - تصفح تفاعلي بالصفحات مع إمكانية التبديل بنقرة واحدة إلى وضع القراءة المستمرة والتمرير العمودي.
   - أزرار السابق والتالي، وشريط التقدم التفاعلي ومؤشر رقم الصفحة (`صفحة X من 11`).
   - دعم كامل للتنقل بأسهم لوحة المفاتيح (`←` للتالي و `→` للسابق وفق منطق RTL).
   - دعم إيماءات اللمس والسحب (Swipe Gestures) على الهواتف والأجهزة اللوحية.

2. **تخطيط RTL قياسي وخصائص منطقية (CSS Logical Properties)**:
   - اعتماد `dir="rtl"` و `lang="ar"` بالكامل مع خط `Cairo` العربي الأنيق.
   - تطبيق قاعدة التخطيط بدقة: **النص في اليمين والرسوم في اليسار** عبر وضع عمود النص أولاً في الـ DOM وشبكة `CSS Grid`.
   - استجابة تلقائية على الشاشات الضيقة (`< 768px`) للتحول إلى عمود واحد (النص أولاً ثم الرسوم).
   - ترتيب الرسوم المتعددة عمودياً في عمود اليسار.

3. **10 رسوم بيانية تفاعلية حقيقية (Recharts)**:
   - تم بناء جميع الرسوم بيولوجياً كعناصر تفاعلية تفاعلية بدلاً من الصور الساكنة.
   - تلميحات مخصصة عند المرور (Interactive Tooltips)، وألوان الهوية الجزائرية والحزبية (أخضر زمردي، أزرق، برتقالي، أحمر).
   - **فصل كامل للبيانات** في ملف منفصل `src/data/charts.ts` لتسهيل تحديث وتعديل الأرقام مستقبلاً دون المساس بالكود.

4. **فصل كامل للمحتوى النصي**:
   - جميع النصوص مستخرجة بالكامل ومحفوظة في ملف `src/data/content.ts`.

5. **دمج كافة الصور المرفقة الستة**:
   - شعار ولافتة الحملة الرسمية (`party-banner-03.jpg`) على الغلاف.
   - صورة وملصق مرشح الدائرة لعوق محمد رقم 42 (`candidate-mohamed-laouk.jpg`).
   - القائمة الكاملة للمترشحين الـ 54 (`candidates-full-list.jpg`).
   - وثيقة ميثاق الالتزامات والرسالة للمواطن (`commitments-charter.jpg`).
   - الملصق الإرشادي لطريقة التصويت الصحيحة (`voting-guide.jpg`).
   - رمز الاستجابة السريع (`campaign-qr-code.jpg`) للوصول الرقمي السريع.
   - إمكانية تكبير ومعاينة أي صورة بالحجم الكامل عبر نافذة مكبرة (Lightbox Modal).

6. **تصدير وطباعة PDF عالية الجودة**:
   - زر مدمج «تحميل PDF» يستدعي `window.print()` مع تنسيقات `@media print` خاصة تحافظ على التخطيط الثنائي للعمودين وتمنع انقطاع الرسوم بين الصفحات (`break-inside: avoid`).

## 🛠️ التثبيت والتشغيل المحلي

### 1. المتطلبات الأساسية
- تثبيت [Node.js](https://nodejs.org/) (الإصدار 18 أو أحدث، يُفضل v20+).

### 2. تثبيت الحزم
```bash
npm install
```

### 3. تشغيل خادم التطوير
```bash
npm run dev
```
افتح المتصفح على العنوان: `http://localhost:5173/`

### 4. بناء المشروع للإنتاج
```bash
npm run build
```
سيتم إنشاء ملفات الإنتاج المحسنة في مجلد `dist/`.

### 5. معاينة نسخة الإنتاج محلياً
```bash
npm run preview
```

## 🌐 تعليمات النشر (Deployment Guide)

المشروع مبني كـ Single Page Application ثابت (Static SPA) فائق السرعة، ويمكن نشره على أي منصة استضافة سحابية بثوانٍ معدودة:

### 1. النشر على Vercel
- قم بربط مستودع Git الخاص بالمشروع على Vercel.
- الإعدادات التلقائية:
  - **Framework Preset**: Vite
  - **Build Command**: `npm run build`
  - **Output Directory**: `dist`

### 2. النشر على Netlify
- اربط المشروع بـ Netlify.
- أو قم بسحب مجلد `dist` مباشرة إلى لوحة تحكم Netlify Drop.
- أمر البناء: `npm run build` ومجلد التوزيع: `dist`.

### 3. النشر على Cloudflare Pages
- اختر مستودع المشروع.
- حدد إعداد Vite:
  - **Build command**: `npm run build`
  - **Build output directory**: `dist`
